# TATESHOOT - 縦スクロールシューティングゲーム

スマートフォン対応の縦スクロール2Dシューティングゲームです。レトロな雰囲気を持ちながら、完全オリジナルのキャラクター・デザインで作られています。

## 🎮 プレイ方法

### スマートフォン操作

- **左側の仮想スティック**: 自機を移動
- **右側のSHOTボタン**: ショット発射（押しっぱなしで連射）
- **PAUSEボタン**: ゲームを一時停止

#### iPhone Safariでの操作確認

もしタッチ操作が反応しない場合は、以下を確認してください：

1. **ページを完全に読み込む**: Safari でページを開いた直後は、全てのリソースの読み込みが完了するまで待ってください
2. **ページを更新**: Safari の更新ボタン（🔄）をタップしてページをリロード
3. **画面向きを切り替え**: 一度画面を横向き→縦向きに回転させると、レイアウトが再計算されて改善することがあります
4. **デバッグログを確認**: 画面左上（スコア表示の下）に緑色のデバッグログが表示されます
   - スティックをタッチすると「Stick DOWN」
   - ショットボタンをタッチすると「SHOT DOWN」
   - これらが表示されれば、タッチイベントは正しく動作しています
5. **キャッシュをクリア**: Safari の設定から履歴とWebサイトデータを消去
6. **プライベートブラウズモード**: プライベートブラウズモードで開いてみる

**デバッグログが表示されるのに自機が動かない場合**: ゲーム内部のロジックは動作しているので、`START GAME` ボタンを押してゲームを開始してください。

### キーボード操作（PC）

- **矢印キー または WASD**: 自機を移動
- **スペースキー**: ショット発射（押しっぱなしで連射）
- **Pキー**: ゲームを一時停止

## 📖 ゲームルール

### 基本ルール

1. **ライフ**: 3機からスタート
2. **敵との衝突**: ライフが1減少し、1秒間の無敵時間が発生
3. **ライフが0**: ゲームオーバー
4. **スコア**: 敵を倒すとポイント獲得
   - 赤い敵: 100点
   - オレンジの敵: 200点
   - 紫の敵: 300点

### パワーアップシステム

- 敵を倒すと **20%の確率** で黄色い星型アイテムが出現
- アイテムを取得すると **ショットが2方向** に強化
- 強化されたショットでより効率的に敵を倒せる

### 敵の特徴

- **赤い敵**: 体力1、素早い
- **オレンジの敵**: 体力2、中速
- **紫の敵**: 体力3、遅いが高得点

敵は直進パターンとサイン波パターンの2種類の動きをします。

5. **Save** をクリック

## 🛠️ 技術仕様

### 使用技術

- **純粋なHTML5/CSS3/JavaScript** - 外部ライブラリ不要
- **Canvas API** - 60fpsのスムーズな描画
- **requestAnimationFrame** - 最適化されたゲームループ
- **Pointer Events API** - タッチ/マウス/ペン統合サポート（Touch Events も保険として併用）
- **デバッグログ機能** - iPhone Safari での動作確認をサポート

### ブラウザ対応

- iOS Safari 12+
- Chrome (モバイル/デスクトップ)
- Firefox (モバイル/デスクトップ)
- Edge

### iPhoneの最適化

- **セーフエリア対応**: ノッチやホームバーを考慮（`env(safe-area-inset-*)`）
- **viewport-fit=cover**: 全画面表示
- **touch-action: none**: iOSのスクロール/ズームジェスチャーを無効化
- **pointer-events制御**: Canvas とUI要素のタッチイベント競合を回避
- **z-index階層化**: UI要素が確実にタッチを受け取るよう配置
- **setPointerCapture**: ドラッグ中の追従性を向上
- **デバッグログ**: タッチイベントの動作を画面上で確認可能
