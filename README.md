# TATESHOOT - 縦スクロールシューティングゲーム

スマートフォン対応の縦スクロール2Dシューティングゲームです。レトロな雰囲気を持ちながら、完全オリジナルのキャラクター・デザインで作られています。

## 🎮 プレイ方法

### スマートフォン操作

- **左側の仮想スティック**: 自機を移動
- **右側のSHOTボタン**: ショット発射（押しっぱなしで連射）
- **PAUSEボタン**: ゲームを一時停止

### キーボード操作（PC）

- **矢印キー または WASD**: 自機を移動
- **スペースキー**: ショット発射（押しっぱなしで連射）
- **Pキー**: ゲームを一時停止

## 📖 ゲームルール

### 基本ルール

1. **ライフ**: 3機からスタート
2. **敵との衝突**: ライフが1減少し、1秒間の無敵時間が発生
3. **ライフが0**: ゲームオーバー
4. **スコア**: 敵を倒すとポイント獲得
   - 赤い敵: 100点
   - オレンジの敵: 200点
   - 紫の敵: 300点

### パワーアップシステム

- 敵を倒すと **20%の確率** で黄色い星型アイテムが出現
- アイテムを取得すると **ショットが2方向** に強化
- 強化されたショットでより効率的に敵を倒せる

### 敵の特徴

- **赤い敵**: 体力1、素早い
- **オレンジの敵**: 体力2、中速
- **紫の敵**: 体力3、遅いが高得点

敵は直進パターンとサイン波パターンの2種類の動きをします。

## 🚀 GitHub Pagesで公開する方法

### 1. リポジトリの設定

1. GitHubでリポジトリを作成またはプッシュ
2. リポジトリの **Settings** タブを開く
3. 左メニューから **Pages** を選択
4. **Source** で `main` ブランチを選択
5. **Save** をクリック

### 2. 公開URLの確認

数分後、以下のURLでゲームがプレイ可能になります：

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

例: `https://username.github.io/tateshoot/`

### 3. iPhoneでのプレイ

- Safari でURLを開く
- 「ホーム画面に追加」でアプリのように使用可能
- フルスクリーン表示に対応

## 🛠️ 技術仕様

### 使用技術

- **純粋なHTML5/CSS3/JavaScript** - 外部ライブラリ不要
- **Canvas API** - 60fpsのスムーズな描画
- **requestAnimationFrame** - 最適化されたゲームループ
- **タッチイベント** - スマートフォン操作に完全対応

### ブラウザ対応

- iOS Safari 12+
- Chrome (モバイル/デスクトップ)
- Firefox (モバイル/デスクトップ)
- Edge

### iPhoneの最適化

- **セーフエリア対応**: ノッチやホームバーを考慮
- **viewport-fit=cover**: 全画面表示
- **タッチ操作最適化**: ユーザビリティを重視した配置
